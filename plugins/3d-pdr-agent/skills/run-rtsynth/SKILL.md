# Run RTsynth

## When To Use
- You already finished 3D-PDR and have `sims_*` folders under `INPUT/SELECTED/.../snapshots/<id>/`.
- You want RTsynth multi-angle outputs for one or more `sims_*` runs.
- You want outputs organized under `Products/` while preserving source folder structure.
- You want a run-complete flag in each `sims_*` folder to avoid duplicate work.

## Inputs To Collect
- Target run folders:
  - One or more `sims_*` folders, or
  - Snapshot ids plus simulation folder and run-id filter.
- Angle mode:
  - HEALPix mode: `level > 0` (RTsynth computes many directions automatically), or
  - Explicit direction mode: list of `(theta, phi)` pairs with `level = 0`.
- Runtime controls:
  - `force` rerun (default: off)
  - Optional explicit velocity file name (default: `snapshot_<snapshot>_v.dat` from the pre-step skill)

## Required Preconditions
- RTsynth source exists at `RT-synth/RT-synth/`.
- RTsynth binary is buildable from current source (`make` succeeds).
- 3D-PDR outputs exist in each target folder, including at least:
  - `*_run.RTspop.fin`
  - `*_run.pdr.fin`
- Velocity file exists in each target snapshot folder (normally generated by `/curate-hydro`):
  - `snapshot_<snapshot>_v.dat`
- Target Products path is writable.

## Procedure
1. Resolve target `sims_*` folders.
   - Expected source shape:
     - `INPUT/SELECTED/<sim>/snapshots/<snapshot>/<sims_*>/`
  - Verify required RT input files are present.
  - Verify default velocity file exists before run.

2. Apply rerun decision using a flag file in each `sims_*` folder.
   - Flag path:
     - `<sims_*>/.rtsynth.done`
   - If flag exists and `force` is off: skip this target and report as skipped.
   - If `force` is on: continue and overwrite outputs/flag.

3. Build RTsynth executable when needed.
   - Build from `RT-synth/RT-synth/` using `make`.
   - Expected executable after build:
     - `RT-synth/RTsynth`

4. Prepare a run-specific RTsynth parameter file.
   - Create a local params file per target (example name):
     - `<sims_*>/paramsRTsynth_local.dat`
   - Fill key fields:
     - `directory` = absolute path to `<sims_*>`
     - `outdir` = temporary local output folder under `<sims_*>` (for run isolation)
     - `prefix` = base prefix matching 3D-PDR outputs (for example `snapshot_810_run`)
     - angle settings = either HEALPix `level` or explicit `(theta, phi)`
   - Keep `nxc/nyc/nzc`, `screeni/screenj`, and line settings consistent with the 3D-PDR grid and science target.

5. Run RTsynth.
   - Command pattern:
     - `RT-synth/RTsynth -p=<paramsRTsynth_local.dat>`
   - For explicit angle lists, run once per `(theta, phi)` pair or generate per-angle param files.
   - For HEALPix mode, set `level > 0` and run once.
  - If any required input is missing for a target (including velocity), mark failed and continue with other targets.

6. Move/copy outputs into `Products/` with preserved structure.
   - Destination root:
     - `Products/RTsynth/`
   - Preserve source hierarchy below `INPUT/SELECTED`:
     - `Products/RTsynth/<sim>/snapshots/<snapshot>/<sims_*>/`
   - Copy RT result files (for example `RT_*_theta_phi_*.dat`, `RT_vel_*`, `RT_tau_*`) and optional logs/params snapshot.

7. Write completion flag in each processed `sims_*` folder.
   - Write `<sims_*>/.rtsynth.done` with at least:
     - timestamp
     - angle mode and values
     - params file used
     - Products destination path
   - This flag is the canonical marker that RTsynth ran for that folder.

8. Validate and summarize.
   - Check destination folder under `Products/RTsynth/.../<sims_*>/` exists and is non-empty.
   - Confirm `.rtsynth.done` exists in each successful source folder.
  - Confirm velocity file path used for each successful run and include it in report.
   - Report per-target status: success, skipped (flag present), or failed.

## Decision Rules
- Default behavior is idempotent: do not rerun if `.rtsynth.done` exists.
- Use `force` only when user explicitly requests rerun.
- If angle coverage request is broad/unknown, prefer HEALPix mode.
- If user requests exact viewpoints, use explicit `(theta, phi)` list.
- Default output root remains `Products/RTsynth/`.
- Prefer `snapshot_<snapshot>_v.dat` from `/curate-hydro`; only ask for an explicit velocity file when that default is missing.
- Never silently regenerate velocity files in this skill; velocity creation belongs to `/curate-hydro`.

## Completion Checklist
- RTsynth executable is available.
- Each requested target has produced RT outputs.
- Outputs are in `Products/RTsynth/...` with preserved folder structure.
- Each successful `sims_*` folder contains `.rtsynth.done`.
- Final report includes what ran, what was skipped, and where outputs were written.

## Example Prompts
- `Use /run-rtsynth for sims_1_N128_hpc001 with HEALPix level 1 and no force.`
- `Run /run-rtsynth for snapshot 810 and 3000, explicit angles (90,0), (90,90), (90,180), and force rerun.`
- `Apply /run-rtsynth to all sims_* under one simulation and skip already flagged runs.`
